How Data Flows In — Three Levels of Maturity

The product evolves from simple CSV uploads (ship-today) to direct system integrations (v2) to fully agentic data capture (the long-term vision). Each level is strictly additive.

LEVEL 01 MVP · SHIP NOW

Manual Upload

User exports CSVs from existing systems and uploads to the workspace. Ugly but honest — every GovCon already has these exports sitting in Deltek or Unanet.

Timesheet CSV Expense CSV Sub invoice PDFs Manual CDRL toggle
LEVEL 02 V2 · 6–12 MONTHS

Direct Integrations

APIs pull data automatically. Dashboard updates itself. No upload friction. This is where the product stops feeling like a tool and starts feeling like infrastructure.

Deltek API Unanet API Jira / MS Project WAWF / PIEE
LEVEL 03 VISION · AGENTIC

Ambient Agents

AI agents watch email, Slack, and inboxes. Mods, deliverable acknowledgments, CPARS feedback — all captured automatically. This is the "GovDash for operations" endgame.

Email watcher Slack listener Auto-mod diff CO correspondence

Existing Stack vs New Build

~60% of the infrastructure is already built for PriceIQ. The post-award platform is an extension, not a rewrite.

Reused from PriceIQ

~60% of stack
intelligent_parser.py
Extended to read awarded contract packages (CLINs, CDRLs, clauses).
Agno agent framework
Powers every post-award agent (MSR writer, clause watcher, etc.).
FAISS · Pinecone
Semantic search for clause Q&A and CDRL lookup — zero new infra.
calculation_service.py
Becomes the burn engine and the indirect rate forecaster.
Multi-tenant Mongo · RBAC · Auth · Billing
Organization isolation, roles, Stripe — all reused as-is.
React data grid · Zustand · Next.js
Excel-like UIs for CDRL and CLIN trackers — same UX pattern.

New to Build

~40% of stack

New Zustand store + dashboard route sitting alongside proposals.

Deltek, Unanet, Jira, WAWF — fake with CSV in MVP, build later.
