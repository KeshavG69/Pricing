## Common Questions

**Do I need to install anything?**
No! PriceIQ is a web-based platform. Just visit the site, create an account, and start working. No downloads or installations required.

**Is there a free trial?**
Yes, you can create an account and explore the platform. Contact our sales team for pricing information.

**Can I invite team members?**
Yes! Once your account is created, organization admins can invite team members. See [Inviting Team Members](../team-organization/02-inviting-team-members.md).

**What if I already have an account?**
Skip to [Creating Your First Proposal](03-first-proposal.md) to start uploading documents.

**How long does document processing take?**
Typical documents process in 30-60 seconds. Complex documents with many positions may take 2-5 minutes. See [What Documents Can I Upload?](05-supported-documents.md) for details.
